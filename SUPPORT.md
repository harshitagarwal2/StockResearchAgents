# Support

StockResearchAgents is an early-stage, evidence-first research capability. Community support is best-effort and does not include financial, investment, legal, entitlement, or provider-access advice.

## Before requesting help

1. Start with [Getting started](docs/GETTING_STARTED.md) and the [documentation map](docs/README.md).
2. Check [Operations](docs/OPERATIONS.md) for state, lifecycle, export, viewer, and recovery questions.
3. Check [Integration](docs/INTEGRATION.md) for Python, MCP, and harness boundaries.
4. Check the [proof ledger](docs/FEATURE_PARITY.md) and [live-provider matrix](docs/LIVE_MATRIX.md) before assuming a provider or runtime capability exists.
5. Search existing issues for the exact command, error, contract identifier, or adapter name.

## Open an issue

Use the bug or feature template. Include a minimal reproduction, version or commit, Python version, operating system, affected interface, and truthful `fixture`, `historical_replay`, or `live` status.

Sanitize all diagnostics. Never post credentials, authorization headers, cookies, signed URLs, private portfolio data, raw licensed content, or unrelated browser/session state.

## Security reports

Do not report a vulnerability in a public issue. Follow the private instructions in [SECURITY.md](SECURITY.md).

## Product boundary

StockResearchAgents does not execute trades, connect to brokers, mutate portfolios, or guarantee source access, evidence completeness, forecast accuracy, or investment performance. A successful deterministic fixture or contract validation is not proof of live research quality.
